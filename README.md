# Claude FastAPI Starter

Template for FastAPI backends built with Claude Code.

## Use
1. GitHub: click **Use this template** and name the repo `<project>-api`.
2. Clone it, edit the top section of `CLAUDE.md` (project, data model, endpoints, env vars).
3. Run `claude`, then `/scaffold-api` once to generate the skeleton.

## Included
```
CLAUDE.md                    project memory, conventions, rules
.claude/settings.json        permissions (blocks .env, force push)
.claude/skills/              /scaffold-api /new-endpoint /new-migration /test /commit
.claude/agents/              code-reviewer, test-writer, db-reviewer
.env.example
```

## Improve the template
When a skill or rule proves useful in a project, copy it back here.
